# Запись к репетитору

## Назначение

Приложение помогает ученику найти репетитора и записаться к нему на занятие.
Программа проверяет, можно ли записаться на выбранное время, считает
стоимость занятия с учетом скидок и сообщает, подтверждена ли запись.

## Целевая аудитория

- школьники и студенты, которым нужен репетитор;
- родители, которые записывают ребенка на занятия;
- репетиторы, которые ведут частные уроки.

## Предметная область

Частные занятия с репетиторами. Репетитор ведет определенный предмет,
работает в свои часы и берет фиксированную цену за час. Ученик выбирает
дату и время, оплачивает занятие со своего баланса. Для первого занятия
и для длинных занятий действуют скидки.

## Основные сущности

- Ученик (имя, баланс);
- Репетитор (ФИО, предмет, цена за час, рабочие часы);
- Предмет;
- Занятие (дата, время начала, длительность, стоимость);
- Запись (ученик, репетитор, занятие, статус).

## Основные функции

- расчет стоимости занятия со скидкой (первое занятие -20%, от 2 часов -10%);
- проверка даты и времени занятия (не в прошлом, не в воскресенье,
  в рабочие часы репетитора);
- проверка возможности записи (совпадает предмет, хватает денег на балансе)
  и вывод статуса записи.

## Запуск

```
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux / macOS
python main.py
```

## План развития

На следующих этапах планируется:

- несколько репетиторов и поиск по предмету и цене;
- разработка веб-приложения на Django;
- подключение базы данных;
- регистрация учеников и репетиторов;
- отзывы и рейтинг репетиторов;
- разработка API;
- контейнеризация приложения в Docker;
- настройка CI/CD.
